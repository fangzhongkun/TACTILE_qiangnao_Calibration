# 设备

本模块用来适配不同协议和格式的设备。一般需要写两部分功能：

1. `xxx-packager` 串口帧的解包/打包
2. `xxx-device` 设备功能的适配，需要标定设备的一些指标参数，以及对上层提供设备功能的接口

## packager

需要实现以下两个接口

- `pack()` 打包，上位机发送控制指令使用
- `unpack()` 解包，上位机接受数据使用

## device

需要继承并实现`Device`虚基类，主要功能函数

- `onarrived` 回调函数， 当解包完成，并经过设备的特殊处理后，调用该回调函数提供数据帧
- `capacities()` 设备功能标志
- `enable()` 开启/关闭设备的功能
- `sensors()` 理论上应该是通过通信接口向设备进行查询，也可以直接设置。传感器的参数，其中量程最需要设置，后续的数据展示和渲染是基于这个量程
